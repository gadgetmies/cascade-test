## 2026-07-05 - Path Traversal and Directory Deletion Prevention
**Vulnerability:** The CLI runner allowed arbitrary directory deletion via the `--coverage-dir` option by calling `fs.rmSync` on user-provided paths without validation. It also allowed writing test results to arbitrary locations via `--output`. Similarly, `assertFixture` allowed reading/writing files anywhere on the system via `fixtureName` traversal.
**Learning:** `path.join` and `path.resolve` do not prevent directory traversal. Even if a base directory is provided, `..` segments can escape it. Validation using `path.relative` to ensure the resolved path remains within the intended boundaries is a robust prevention pattern.
**Prevention:** Always validate user-provided file paths against a base directory using a utility like `isPathSafe`. This utility should resolve the target path, calculate the relative path from the base directory, and verify it doesn't start with `..` and isn't absolute. Rejection of the base directory itself (empty relative path) can also prevent dangerous operations on the current working directory.
